# sam
Interactive 3D Model of Old Sports Cars Website
## Description
This project is a website that showcases interactive 3D models of old sports cars using React and Node.js (Express).
## Requirements
* Node.js
* npm
* React
* Express
## Installation
1. Clone the repository: `git clone https://github.com/your-username/sam.git`
2. Install dependencies: `npm install` and `npm install --prefix client`
3. Start the server: `npm run dev`
